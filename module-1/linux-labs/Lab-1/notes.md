- Các lệnh sử dụng trong bài lab này:
1. 'ls' -> xem danh sách thư mục 
2. 'mkdir' -> tạo directory 
3. 'rmdir' -> xóa directory
4. 'touch' -> tạo ra file rỗng
5. 'echo' -> sử dụng để in ra màn hình terminal. Sử dụng với dấu '>>' để viết vào file (sẽ tạo ra file mới nếu như file chưa tồn tại)
6. 'cat' -> in ra màn hình
7. 'nano/vim' -> lệnh dùng để ghi vào tệp tin
8. 'cp' -> copy thư mục hoặc tệp tin
9. 'mv' -> di chuyển thư mục hoặc tệp tin. Giống cut bên window
